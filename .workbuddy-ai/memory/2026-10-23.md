## 当前 get_order 逻辑（供后续参考）

1. 两参都不传 → `isError` 提示至少传一个
2. `order_id` 含 `@` → `isError` 引导改用 `email`
3. `order_id` 非空 → `ordersRequestSingle()`（先 hidden=false，空了再查 hidden=true，短路）
   - 命中 → 全量详情，结束（email 被忽略）
   - 未命中且无 email → 「未找到订单号 XXX 对应的订单」（isError=false）
   - 未命中且有 email → prefix 前缀，继续走邮箱
4. 邮箱 → `ordersRequestBoth(email, limit=20)`（两次查询 + 按 id 去重 + created_at 倒序 + 截断）
   - 0 笔 → 空结果；1 笔 → 全量详情；多笔 → 每笔全量详情（约 6.4KB/笔，>7~8 笔触顶 50000 截断）
